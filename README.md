# Sprint_5

- `tests/test_login.py` — проверяет вход в аккаунт и выход: корректная авторизация по email/password, появление аватара и имени пользователя, кнопка выхода работает.
- `tests/test_registration.py` — проверяет регистрацию: успешная регистрация нового пользователя (отображение аватара/имени) и обработка ошибок при некорректном/существующем email.
- `tests/test_ad.py` — проверяет создание объявления:
	- `test_create_ad_not_logged_in` — при попытке создать объявление неавторизованным пользователем происходит редирект на страницу входа;
	- `test_create_ad_logged_in` — (авторизованный сценарий) открывает форму создания объявления, заполняет поля (`Название`, `Описание`, `Стоимость`) и публикует объявление; после публикации проверяет, что объявление появилось в списке (рекомендуется искать по уникальному заголовку).
